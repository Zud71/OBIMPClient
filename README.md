# OBIMP Client (Bimoid)

Консольный клиент протокола **OBIMP** (Open Buddy Impulse Messaging Protocol) на C# .NET 8.

Каркас сгенерирован ИИ на основе описания протокола в файле OBIMP_Draft_1_1_Rev_C.txt с последующей доработкой.

## Общее описание

OBIMP — открытый протокол мгновенного обмена сообщениями, обеспечивающий:

- **Авторизацию** — безопасный вход с MD5-хешированием пароля
- **Список контактов** — группы, контакты, заметки, настройки приватности, авторизация
- **Presence** — статусы присутствия с настраиваемыми значениями и способностями (capabilities)
- **Мессенджер** — текстовые сообщения, уведомления о наборе текста
- **Каталог пользователей** — поиск, детали аккаунта, обновление данных
- **Аватары** — загрузка и получение аватаров пользователей (PNG, MD5)
- **Передача файлов** — прямая, обратная и прокси-подключение
- **Транспорты** — подключение внешних мессенджеров с настройками

Пакеты OBIMP имеют бинарный формат: заголовок 17 байт + массив wTLD (тип-длина-данные), все числа — Big-Endian.

## Требования

- .NET 8.0 SDK
- OBIMP-сервер (порт: `7023`, TLS: `7033`)

---

## Быстрый старт

```bash
cd OBIMPClient
dotnet restore
dotnet build
dotnet run
```

## Структура проекта

```
OBIMPClient/
├── Client/                 Основная логика клиента
│   ├── ObimpClient.cs      Вход, регистрация, сессия
│   ├── ObimpClient.Actions.cs  Сообщения, контакты, авторизация
│   └── ObimpClient.Presence.cs Presence и статусы
├── Models/                 Модели и константы
│   ├── Constants.cs        Константы протокола
│   ├── Contact.cs          Контакты, сообщения, чаты
│   └── ObimpPacket.cs      Пакет, заголовок, wTLD/stTLD
├── Network/                Сетевой слой
│   ├── NetworkManager.cs   TCP-соединение, чтение/отправка
│   └── Serializer.cs       Сериализация/десериализация
├── Security/               Безопасность
│   └── PasswordHasher.cs   MD5-хеширование паролей
└── Program.cs              Точка входа
└── ext/
    └── obimp.lua           Скрипт для wireshark для расшифровки протокола на лету
```

Подробное описание каждой функции и константы содержится в XML-комментариях исходного кода.

## Реализованный функционал

### Авторизация (BEX 0x0001)

| Шаг | BEX | Подтип | Статус |
|-----|-----|--------|--------|
| Приветствие клиента | `COM_CLI_HELLO` | 0x0001 | ✅ Реализовано |
| Ответ сервера | `COM_SRV_HELLO` | 0x0002 | ✅ Реализовано |
| Вход | `COM_CLI_LOGIN` | 0x0003 | ✅ Реализовано |

### Список контактов (BEX 0x0002)

| Функция | BEX | Подтип | Статус |
|---------|-----|--------|--------|
| Запрос параметров | `CL_CLI_PARAMS` | 0x0001 | ✅ Реализовано |
| Запрос списка | `CL_CLI_REQUEST` | 0x0003 | ✅ Реализовано |
| Добавление элемента | `CL_CLI_ADD_ITEM` | 0x0007 | ✅ Реализовано |
| Удаление элемента | `CL_CLI_DEL_ITEM` | 0x0009 | ✅ Реализовано |
| Запрос авторизации | `CL_CLI_SRV_AUTH_REQUEST` | 0x000D | ✅ Реализовано |
| Ответ на авторизацию | `CL_CLI_SRV_AUTH_REPLY` | 0x000E | ✅ Реализовано |
| Отозвать авторизацию | `CL_CLI_SRV_AUTH_REVOKE` | 0x000F | ✅ Реализовано |

### Presence (BEX 0x0003)

| Функция | BEX | Подтип | Статус |
|---------|-----|--------|--------|
| Установка параметров | `PRES_CLI_SET_PRES_INFO` | 0x0003 | ✅ Реализовано |
| Установка статуса | `PRES_CLI_SET_STATUS` | 0x0004 | ✅ Реализовано |
| Активация broadcast | `PRES_CLI_ACTIVATE` | 0x0005 | ✅ Реализовано |

**Поддерживаемые статусы:** ONLINE, INVISIBLE, FREE_FOR_CHAT, AWAY, OCCUPIED, DO_NOT_DISTURB

### Мессенджер (BEX 0x0004)

| Функция | BEX | Подтип | Статус |
|---------|-----|--------|--------|
| Отправка сообщения | `IM_CLI_MESSAGE` | 0x0006 | ✅ Реализовано |
| Прием сообщений | `IM_SRV_MESSAGE` | 0x0007 | ✅ Реализовано |
| Уведомление о наборе | `IM_CLI_SRV_NOTIFY` | 0x0009 | ✅ Реализовано |

**Поддерживаемые типы сообщений:** UTF-8, RTF

### Не реализовано

| BEX-тип | Описание |
|---------|----------|
| BEX 0x0005 | Каталог пользователей (UD) |
| BEX 0x0006 | Аватары пользователей (UA) |
| BEX 0x0007 | Передача файлов (FT) |
| BEX 0x0008 | Внешние транспорты (TP) |
| MD5-верификация списка контактов | Подпроверка локальной копии |
| Офлайн-сообщения и авторизации | Запрос/удаление офлайн-данных |
| Шифрование сообщений | AES/TDES шифрование |
